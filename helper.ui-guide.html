Mixin Media query Meaning Used

Mixins are desktop-first (max-width). Use them via @use "@root/mixins" as *;.

Prefer the mixins; raw queries are mostly min-width overrides. Breakpoints are not fully unified across the project: mixins use 767 / 991 / 1120 / 1199, utilities (.d-*, .fs-*) use 576 / 768 / 992 / 1200 / 1400 with min-width.
